# Building CookieTin from source

These are the instructions for reproducing the published packages (also for addons.mozilla.org
reviewers).

The extension is written in TypeScript with Preact. `scripts/build.mjs` bundles each entry point
with esbuild into a single IIFE file. The output is **not minified** (`minify: false`) and keeps
the original identifiers, so it stays readable.

## Requirements

- Node.js 20 or newer (tested with 20.20), npm 10
- Any OS (tested on Windows 11; the build uses only Node.js and esbuild)

## Steps

```bash
npm ci
npm run build
```

Output:

- `dist/firefox/` — the Firefox add-on (identical to the submitted package)
- `dist/chrome/` — the Chromium (Chrome / Edge) extension

`npm run package` additionally creates `dist/cookietin-firefox-<version>.zip`,
`dist/cookietin-chrome-<version>.zip` and `dist/cookietin-source-<version>.zip`.

## What goes into the package

| Output | Source |
|---|---|
| `background.js` | `src/background/index.ts` (+ `src/shared/*`) |
| `popup/popup.js`, `manager/manager.js`, `options/options.js` | `src/popup`, `src/manager`, `src/options` (+ `src/shared`, `src/ui`) |
| `*.html`, `*.css`, `icons/`, `_locales/` | copied from `src/` (`_locales` is generated by `scripts/locales.mjs`) |
| `manifest.json` | `src/manifest.json` + per-browser keys added by `scripts/build.mjs` |
| `LICENSE`, `COPYRIGHT`, `THIRD_PARTY_NOTICES.md` | copied from the repository root |

Third-party code in the bundles: Preact 10 (MIT). The `innerHTML` assignments reported by
`web-ext lint` are inside Preact's `dangerouslySetInnerHTML` support, which CookieTin never uses.
The container icons in `icons/containers/` are Mozilla's (MPL-2.0).

## Build with the Cookie Quick Manager add-on ID

`npm run package:cqm` (`node scripts/build.mjs --cqm`) builds the same code with the add-on ID of
the Cookie Quick Manager listing, for shipping CookieTin as its update. See
[store/amo-cqm-handover.md](store/amo-cqm-handover.md).

## Tests

```bash
npm test          # unit tests (node:test via tsx)
npm run lint      # web-ext lint of dist/firefox
npm run test:e2e  # end-to-end tests in Chrome for Testing and Firefox (local test page only)
npm run test:upgrade  # Cookie Quick Manager 0.5rc2 → CookieTin update in Firefox
```

`npm run media` regenerates the screenshots and the demo GIF (needs ffmpeg for the GIF).
